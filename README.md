# **G-Code & CAD Processing Toolset for GRBL / Laser / CNC**

A comprehensive Python-based desktop suite for processing, healing, simulating, and auditing G-Code and CAD files (DXF, SVG, PNG, G-Code). Designed specifically for CNC routers, laser engravers, and GRBL-based controllers.

## **📁 Repository Structure**
~~~ bash

├── README.md            \# Project documentation  
├── auditor.py           \# G-Code auditor & path distance / area calculator  
├── main.py              \# Main DXF/SVG/PNG processor & G-Code generator (Healing Corner included)  
├── requirements.txt     \# Python dependency list  
└── simulator.py         \# Real-time interactive G-Code execution simulator
~~~
## **🚀 Overview of Tools & Components**

### **1\. main.py — Vector Processing & G-Code Generator**

The core engine for importing design files, repairing defective geometries, and generating clean G-Code outputs.

> * **Healing Corner Engine:** Automatically detects and heals broken vertices, open polylines, and overlapping arcs often generated by export tools like EasyEDA DXF or raw vector traces.  
> * **Multi-Format Import Support:**  
  * **DXF:** Direct parsing with entity healing.  
  * **SVG:** Path parsing into linear/arc movements.  
  * **PNG / Raster:** Image edge-detection and vectorization for engraving/cutting paths.  
> * **Export Configurator:** Generates highly customizable GRBL-compliant G-Code (.gcode, .nc, .txt).

### **2\. auditor.py — G-Code Auditor & Area Calculator**

An analytical tool built with Tkinter and Matplotlib to inspect and verify G-Code files prior to sending them to the machine.

> * **Detailed Path Breakdown:** Separates rapid travel distances ($G00$) from actual cutting/engraving paths ($G01$, $G02$, $G03$).  
> * **Closed-Polygon Detection & Area Calculation:** Calculates the surface area ($\\text{mm}^2$) for individual closed shapes using the Shoelace algorithm.  
> * **Visual Bounding Boxes:** Highlights and tags individual objects with visual bounding frames and IDs.  
> * **GRBL & Modal State Support:** Accurately parses unit codes (G20/G21), positioning (G90/G91), laser modes (M3/M4/M5), feed rates (F), and spindle/laser power (S).

### **3\. simulator.py — Interactive G-Code Simulator**

A lightweight, interactive G-Code previewer built on Python's turtle graphics engine and Tkinter.

> * **Real-time Trajectory Animation:** Visualizes toolhead movement with variable simulation speeds.  
> * **Modal Motion Memory:** Handles standard GRBL streaming logic where coordinates (X, Y) inherit active motion modes without explicit $G$-code repetition on every line.  
> * **Dynamic Styling:** Distinguishes rapid travel moves (dashed red lines) from laser active / cutting passes (solid black lines).  
> * **Interactive Navigation:** Supports Pan and Zoom controls alongside a live terminal line-highlighter.

## **⚙️ Supported G-Code & GRBL Parameters**

| Parameter / Code | Description |
| :---- | :---- |
| G20 / G21 | Imperial (inches) / Metric (millimeters) unit selection |
| G90 / G91 | Absolute / Incremental positioning modes |
| G00 / G0 | Rapid positioning travel |
| G01 / G1 | Linear interpolation cutting move |
| G02 / G03 | Clockwise / Counter-clockwise arc interpolation |
| M03 / M04 | Spindle / Dynamic Laser mode ON |
| M05 | Spindle / Laser OFF |
| F\<val\> | Feed rate (mm/min) |
| S\<val\> | Spindle speed / Laser power intensity |
| X, Y, Z, I, J | Axis coordinates and arc center offsets |
